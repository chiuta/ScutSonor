## Features

- Four modes: harsh sweep 2–8 kHz, experimental ultrasound, two-tone siren, and a speaker test that shows where your phone speaker stops.
- Flashlight strobe (2.5 Hz, low photosensitivity risk) – a visual deterrent that also draws human attention.
- Click-free ramps, soft-clipping limiter for maximum loudness, wake lock, daylight high-contrast mode.
- Calm-behaviour guide for a dog or a pack, and where to report stray dogs.

## Usage

Open the page online, or download `index.html` and open it in a recent browser (Chrome on Android works best). No installation, no build.

## Limits

- Evidence that sound deters dogs is weak; this is an aid, not a shield, and does not replace safe behaviour or calling 112.
- Phone speakers barely reproduce ultrasound above ~15–16 kHz; the “Signal” bar shows the generated signal, not the real speaker output.
- Interface in Romanian only for now.

## Privacy

Everything runs in your browser; no account, no tracking, no network requests, nothing is stored.
